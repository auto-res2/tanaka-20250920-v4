# Novelty
既存研究を詳細に対比すると、AMPS は (1) Strictly Proper Scoring Rules による校正改善、(2) FIGA 由来の edit-contrast による微粒度アラインメント、(3) ScaleGrad/UL 系が狙う反復抑制を、一つのトークン単位損失に統合している点が最も新しい。関連論文のいずれも『校正 + アラインメント』を同時に最適化する目的関数は提案していない。FIGA は edit mask だけ、Proper-Score 論文は校正だけ、ScaleGrad は多様性だけを扱う。さらに AMPS はエントロピーに基づき λ_t を動的に決定し、γ,α,β のチューニングをほぼ不要にした。マルチオブジェクティブを RL や二段階 fine-tuning を用いずに単一の back-prop で実現する設計は過去文献に見当たらない。よって“目的関数の統合”および“自動重み付け”の二点で新規性がある。ただし各構成要素自体（CE, Brier, FIGA mask）は既知であり、統合のアイデアは拡張的と評価できる。

# Significance
校正の欠落は RLHF/DPO 系の実運用上の大きな問題であり、逆に Brier/Spherical のみでは指示追従や有用性が不足する。AMPS が一回の LoRA ファインチューニングで MT-Bench を維持しつつ ECE を 50% 改善できるなら、(a) 商用デプロイ時の信頼度提示、(b) RL を要さない低コスト開発、(c) ハイパーパラメータ探索の削減、を同時に達成できるため実社会での利便性が高い。また学術的にも「Proper Scoring Rule × Edit Supervision」という未踏領域を開き、多目的最適化・適応重み付けの研究を促進する。実験設定が LLaMA 7B/13B、各種ベンチで検証されており汎用性の見通しもある。ただし効果はまだ中規模モデル・英語中心で、真のブレークスルーかは追加検証が必要。
